# Getting help

- **Questions about a repository:** start with its `README.md`, then contact the team listed in its `CODEOWNERS` file.
- **Bugs or feature requests:** create an Azure Boards work item or a Transformation Help Desk case. GitHub Issues are disabled in most repositories so that work is tracked in one place.
- **Access to the organization or a repository:** request it through a Transformation Help Desk case.
- **Security vulnerabilities:** do not use any of the above. Follow [SECURITY.md](SECURITY.md).
