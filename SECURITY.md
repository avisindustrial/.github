# Security policy

## Reporting a vulnerability

Email **[security@avisindustrial.com](mailto:security@avisindustrial.com)** to report a suspected security vulnerability in any `avisindustrial` repository or the software built from it.

**Do not** open a public issue, pull request or discussion about a vulnerability.

Please include:

- The affected repository, component or URL
- A description of the issue and its potential impact
- Steps to reproduce, proof of concept, or sample requests
- Any known mitigations
- How to contact you for follow-up

## What to expect

- We aim to acknowledge reports within **3 business days**.
- We will keep you informed while we investigate and fix the issue.
- We ask that you give us reasonable time to resolve the issue before disclosing it publicly.

## Exposed secrets

If you find a credential, token or key in any repository, report it to the address above right away. If you committed it yourself, rotate or revoke it first, then report it. Removing it from Git history is not enough.

## Scope

This policy covers software in the `avisindustrial` GitHub organization. For other concerns about Avis Industrial or its operating companies, contact the company through [avisindustrial.com](https://www.avisindustrial.com/).
