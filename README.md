# .github

Organization-wide defaults for the `avisindustrial` GitHub organization.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public profile shown on [github.com/avisindustrial](https://github.com/avisindustrial) |
| `CONTRIBUTING.md` | Default contribution guide for every repository |
| `SECURITY.md` | How to report a security vulnerability |
| `CODE_OF_CONDUCT.md` | Expected conduct in our repositories |
| `SUPPORT.md` | Where to get help |
| `.github/pull_request_template.md` | Default pull request template |

GitHub uses these files in any repository that does not have its own copy. A repository overrides a default by adding a file with the same name.

**This repository is public.** Keep everything here generic: no internal hostnames, system details, credentials, customer or employee data, or anything classified above `public`.
